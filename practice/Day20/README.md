# Day 20 - Promises, Async/Await and Fetch API

## Assignment

This project demonstrates JavaScript Promises, async/await, fetch(), .then(), .catch(), error handling, and Promise.all().

## Exercises

- Exercise 1: Fetch USD to ETB exchange rate
- Exercise 2: Rewrite a .then() chain using async/await
- Exercise 3: Handle network errors and HTTP 404 errors
- Exercise 4: Use Promise.all() to fetch two items in parallel

## Mini-Project: Country Facts Page

The Country Facts Page allows users to search for a country and displays:

- Country name
- Capital
- Population
- Region
- Currency
- Flag

The page shows a loading state while fetching data and displays a friendly error if the country cannot be found.

## API Used

REST Countries API:

https://restcountries.com/v3.1/name/

Frankfurter Exchange Rates API:

https://api.frankfurter.dev/

## How to Run

1. Open the Day20 folder.
2. Open index.html in a web browser.
3. The page will automatically load Ethiopia.
4. Enter another country name and click Search.
