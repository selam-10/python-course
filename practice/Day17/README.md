# Day 17 – Habesha Eatery Order Module

A small JavaScript module for calculating Habesha Eatery orders in ETB.

## Features

* Calculates order subtotal using `reduce()`
* Applies a member discount
* Adds VAT
* Formats prices in ETB
* Uses a closure to keep a private running order number
* Generates numbered receipts

## How to Run

From the `python-course` folder:

node practice/Day17/run.js

## Expected Output

#1: 465.75 ETB
#2: 569.25 ETB
