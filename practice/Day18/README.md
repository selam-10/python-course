# Day 18 - Addis Market Order Summary

This project practices JavaScript modules, map, filter, reduce,
destructuring, and spread.

## Files

- pricing.js - Contains pricing and formatting functions.
- orders.js - Contains the sample order data.
- summary.js - Processes the orders and prints the summary.
- README.md - Project information.

## How to Run

Run the following command from the python-course folder:

node practice/Day18/summary.js
